Glamorous Toolkit holds the materials for an investigation. You reach it through the `gt` tools. The task is on the Lepiter page with pageUid `{PAGE_UID}` in the database with databaseId `{DATABASE_ID}`. `listObjectStorage` lists the starting objects.

Work in this order:

1. Read the task page. Call no other tool before step 2.
2. Write your first impression, item 1 of "Your answer", to `{OUT}/first-impression.md`. Write this file only once and do not change it later.
3. Investigate with the tools you have.
4. Write your complete answer, items 1 to 5 of "Your answer", to `{OUT}/answer.md`.

Work alone. Nobody answers questions during the session.
