The materials of the [experiment](../v08-showcase-value-qualification-experiment.md) (spec §4–§5).
They were written after owner checkpoint 1 ([Step 1](../v08-showcase-value-qualification-step1.md),
D5) and are frozen before the first session. `SHA256SUMS` holds the digest of every file here, and of
the v0.8 [`plan-key.json`](../../0.8.0/i4-evidence/plan-key.json), which is used unchanged.

|---|---|

| `settings/settings.{F+,F-,T+,T-}.json` | the Claude Code settings template of each type (spec §4.2, §6.1), generated by the same script |

| `comprehension-key.json` | Q1–Q5 (spec §5.2) |
| `claim-rules.json` | U1–U6, the counting rule and the U3 resolution (spec §5.3) |
| `criteria.json` | the criteria (spec §5.4) |
| `catalogue/R1.txt` | the R1 answer: the v0.8 capture `S1-13-groups-describe.txt`, verbatim |
| `catalogue/r2-list.json` | the R2 repositories, the team-scoped repositories, the excluded one, and the reply texts |

Locations in `matrix.json` are relative to the workspace `src/` directory. They were checked against
the clones at the [v0.7.2 freeze commits](../../0.7.2/i2-evidence/sokol111/freeze.md).
