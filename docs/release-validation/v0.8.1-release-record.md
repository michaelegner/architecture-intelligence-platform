## What the release changed

An interoperability patch ([notes](v0.8.1-release-notes.md)):
- two agent skills served through the MCP Skills extension (SEP-2640): `aip-reading-answers`
  always, and `aip-binding-picture` only with `experimental.binding-picture`;
- MCP `2026-07-28` admitted on `/mcp` ([ADR 0018](../adr/0018-admit-mcp-2026-07-28.md)); the
  `2025-11-25` path is unchanged from v0.8.0 apart from release-version metadata;
- `subscriptions/listen` declined on both eras;
- the ingress guard's body-replay fix;
- the base image `python:3.14.10-slim` and the build-time `uv` 0.13.10, which closes the four
  `rustls` advisories that v0.8.0 accepted;
- a ninth release golden-path phase, `skills`.

No tool, schema or answer semantics changed.
