## What v0.4.1 proves

> AIP v0.4.1 hardens the qualification and messaging semantics `v0.4.0` shipped, and commits
> reproducible evidence of current whole-graph read cost — before any broader discovery work
> widens the surface those semantics govern. It adds no discovery source, Canonical Model family,
> or MCP tool.

`v0.4.0` made AIP's already-qualified architecture intelligence safely consumable by external MCP
clients. `v0.4.1` does not add another architecture-intelligence dimension — it closes two real
correctness gaps found by the post-`v0.4.0` architecture review and supplies the baseline
measurement half of a third:

- **One declared-versus-observed semantic owner.** The analysis/REST path and
  `ArchitectureIntelligenceService`/MCP previously stated the same qualification rule twice, never
  cross-checked. Both now share one kernel (`app/qualification/declared_observed.py`), proven
  equivalent by a real-Neo4j differential fixture — qualification mismatches = 0, coverage
  mismatches = 0 — which found and fixed one real pre-existing coverage-window bug in the process.
- **Runtime messaging now requires two independent guards** before minting any canonical fact: a
  Queue-compatible destination guard (default-deny) and a safe service-identity guard (refuses the
  real OpenTelemetry SDK placeholder family). Either guard's refusal creates zero
  Service/Queue/Evidence/relation artifacts, confirmed against the real captured Quarkus Kafka and
  Apache Airflow/Celery attribute shapes.
- **A committed, reproducible read-cost benchmark** makes AIP's current whole-graph snapshot/read
  cost measurable, supplying the baseline half of
  [ADR 0011](../adr/0011-snapshot-identity-read-cost.md)'s acceptance condition. No cache,
  snapshot-identity change, or retention policy ships in this release.

## Known limitations

- Everything already documented under `v0.4.0` still applies (direct dependencies only, current
  state only, no generic Cypher/graph query surface, local/trusted-network MCP posture, pre-1.0
  contracts).
- Whole-graph read cost grows with total graph/evidence size — this release measures and commits
  that fact reproducibly; it does not remediate it. No snapshot cache, retention/compaction policy,
  or performance SLO exists yet — see [ADR 0011](../adr/0011-snapshot-identity-read-cost.md) and
  [ADR 0012](../adr/0012-observed-evidence-retention.md), both still `Proposed`.
- No topic/pub-sub (Kafka-style) messaging family exists — Quarkus Super Heroes' Kafka topic and
  similar destinations remain unsupported, deliberately, per [ADR 0013](../adr/0013-no-topic-family-without-guards.md).

None of the above represents an incorrect supported claim — each is explicit and bounded.
