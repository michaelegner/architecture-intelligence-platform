## Known limitations (reviewed, not release blockers)

Reviewed against `ROADMAP.md`, root `README.md`, and the draft
[`v0.2.0-release-notes.md`](v0.2.0-release-notes.md) — all still accurate as of the candidate commit:

- Canonical Model, REST API surface, Graph Schema, Adapter SPI, and configuration format are not
  yet guaranteed stable pre-1.0 — expect breaking changes on a future minor version bump.
- No Kubernetes/cloud discovery, no gRPC/protobuf adapter, no GraphRAG.
- No broad validation against independent real-world reference systems yet (a separate pre-1.0
  qualification track, not a `v0.2.0` requirement — spec §4 non-goals).
- The natural-language query layer requires an LLM provider API key; deterministic evaluation does
  not.
- DLQ directionality and cross-batch HTTP correlation remain optional, not-yet-added evaluation
  scenarios (both explicitly non-blocking per I4 spec §16-17/§28) — cross-batch correlation itself
  is still exercised live in the runtime demo above, just not as a dedicated evaluation scenario.
