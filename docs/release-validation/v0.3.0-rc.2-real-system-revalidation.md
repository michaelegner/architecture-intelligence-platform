## Why this run exists

Per spec §18.2, `v0.3.0-rc.2` (`eeff933da3a8f1e5fc6749cb9a77bbf2e5123fd1`) differs from the I4.4
candidate (`9f95d48046ab1942bb1a77c9a3a887a542120b98`) — the version/lock fix recorded in
[`v0.3.0-rc.2-candidate-preparation.md`](v0.3.0-rc.2-candidate-preparation.md). §18.1's "candidate
unchanged" shortcut therefore does not apply: this record is the mandatory fresh, full Quarkus and
Airflow revalidation against the literal new candidate, not a source-diff or content-equivalence
argument.
