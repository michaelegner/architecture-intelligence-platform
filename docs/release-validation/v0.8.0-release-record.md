## What the release changed

A demonstration release. The new promise, assessment and projection semantics are experimental and
not a v1.0 contract ([notes](v0.8.0-release-notes.md)):
- the experimental `get_binding_picture` MCP tool and its REST twin, behind
  `experimental.binding-picture` (off by default);
- the EventCatalog source and its promise record;
- topic-only AsyncAPI channels;
- descriptions on the `get_destination_consumers` identifier fields;
- the additive import report schema change.

## Security dispositions (owner)

- **`rustls` in the bundled `uv` binary:** GHSA-c8m5-c952-6cm4 (medium), GHSA-h2v8-394m-p7vv,
  GHSA-vp88-798v-h67f and GHSA-w44r-93j7-qv28 (low), fixed in rustls 0.23.46. They were published on
  2026-10-27, after the v0.7.2 scan. The `uv 0.12.19` binary is the same in the v0.7.2 and v0.8.0
  images, so v0.8.0 did not introduce them, and `uv` runs only at build time (the container starts
  `uvicorn`). **Accepted and recorded; a follow-up re-pins the `uv` build image to one with the fix.**
- **Dependabot GHSA-xcq7-p3pf-p88h (medium):** `opentelemetry-api` ≤ 1.45.0 in
  `harness/locality-capture/app/requirements.txt`, a repository harness that is not part of the image
  (AIP's lock has 1.45.1). **Accepted for this release; fixed after it.**
