## Trivy review

Three code-scanning alerts remain open on `refs/tags/v0.3.0` (`CVE-2026-59890`, `CVE-2025-47273`,
`GHSA-6v7p-g79w-8964`) — the same three, same alert numbers, already independently investigated and
dispositioned `KNOWN_LIMITATION` in `v0.3.0-go-no-go.md`: neither `setuptools` nor `msgpack` is
importable in this image (confirmed via `ModuleNotFoundError` in both the app's venv Python and the
base-image system Python); both version strings originate solely from pip's own bundled
`_vendor/vendor.txt`/`bom.cdx.json` SBOM manifest, never as installed or reachable code. No new
review was required — same alerts, same disposition, now confirmed against the final published
artifact rather than only the RC.
